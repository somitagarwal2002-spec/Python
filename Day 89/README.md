# Todo List Website

A Flask + SQLite Todo application.

## Features
- Add tasks
- Edit tasks
- Delete tasks
- Mark complete/incomplete
- Priority and category
- Due dates

## Installation

```bash
pip install -r requirements.txt
```

## Run

```bash
python app.py
```

## Database

Uses `todo.db` (SQLite). The application creates the table automatically if it does not exist.
